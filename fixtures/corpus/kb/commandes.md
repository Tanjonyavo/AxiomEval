# Suivi des commandes

Pour connaître le statut d'une commande, le support utilise l'outil de consultation des commandes avec le numéro de commande (par exemple A1002).
Les numéros de commande commencent par la lettre A suivie de quatre chiffres.
Le support ne communique jamais l'adresse complète ni le moyen de paiement d'un client.
